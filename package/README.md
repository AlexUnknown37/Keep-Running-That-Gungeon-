# Keep Running

Stops Enter the Gungeon from pausing when you tab out of the game. Handy for co-op, streaming, or a second monitor.

## Settings

In `BepInEx/config/keeprunning.etg.cfg` (or your mod manager's config editor):

- `PauseWhenUnfocused` (default **false**): set to `true` to get the normal pause-on-tab-out back.
- `MuteWhenUnfocused` (default **true**): set to `false` to keep hearing the game while it's in the background.

Restart the game after changing a setting.

## Notes

- Only the automatic pause when you tab out is removed. The pause menu still works normally.
